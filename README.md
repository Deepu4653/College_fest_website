# College Event Website

A simple webpage for a fictional college festival, created using HTML and CSS.

## Sections
- Header and navigation
- Welcome banner
- Event cards
- Event schedule
- Contact information

## Flexbox practice
- `justify-content: center` in the navigation bar
- `flex-wrap: wrap` and `justify-content: space-around` for event cards
- `justify-content: space-between` for schedule rows
- `flex-direction: column` for the mobile navigation

## Files
- `index.html` - webpage content
- `style.css` - webpage design

## Run
Open `index.html` in a web browser.

## GitHub Pages
Upload `index.html` and `style.css` to a GitHub repository. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
